

# Databricks com SQL, Python e PySpark para Análise de Dados em Cloud

[← Voltar ao Portfólio de Engenharia de Dados](https://github.com/joycequoos/Data_Enginer/blob/main/README.md)

Estudo prático da plataforma Databricks — do ambiente gratuito local até um projeto completo em Azure com arquitetura medalhão (bronze/silver/gold).

## Conceitos-base

**Databricks**: plataforma unificada em nuvem para processamento de grandes volumes de dados, IA e engenharia de dados, baseada em Apache Spark e na arquitetura Data Lakehouse. Em poucas palavras: ambiente onde equipes de dados constroem pipelines, analisam dados e treinam modelos de ML no mesmo lugar.

**Apache Spark**: motor de computação open-source para processar Big Data em alta velocidade, com processamento distribuído em memória. Em poucas palavras: a "turbina" que roda cálculos pesados em milhares de máquinas ao mesmo tempo.

**Data Lakehouse**: arquitetura que combina o baixo custo de um Data Lake (armazena qualquer tipo de dado bruto) com a organização e governança ACID de um Data Warehouse. Em poucas palavras: guarda qualquer dado em um só lugar e analisa com a velocidade e segurança de um banco tradicional.
