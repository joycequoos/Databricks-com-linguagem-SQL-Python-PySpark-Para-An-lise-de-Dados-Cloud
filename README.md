### Databricks com linguagem SQL, Python, PySpark Para Análise de Dados Cloud

  O <b>Databricks</b> é uma plataforma unificada em nuvem para <b>processamento de grandes volumes de dados, inteligência artificial e engenharia de dados,</b> baseada em Apache Spark e na arquitetura Data Lakehouse.

Em poucas palavras: é um ambiente onde equipes de dados constroem pipelines, analisam informações e treinam modelos de machine learning no mesmo lugar.

O Apache Spark é um motor de computação em código aberto projetado para processar e analisar gigantescos volumes de dados (Big Data) em alta velocidade, utilizando processamento distribuído e memória RAM.

Em poucas palavras: é a "turbina" que permite rodar cálculos e consultas pesadas em milhares de computadores ao mesmo tempo.

O <b>Data Lakehouse</b> é uma arquitetura moderna que combina o melhor dos dois mundos: a capacidade e baixo custo de um Data Lake (para armazenar dados brutos, estruturados ou não) com a organização, desempenho e governança ACID de um Data Warehouse (usando SQL).

Em poucas palavras: é a estrutura que permite guardar qualquer tipo de dado em um só lugar e analisá-lo com a velocidade e segurança de um banco de dados tradicional.
